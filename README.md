<p align="center"><strong>dsh-injection-molding — 注塑 DFM</strong></p>

注塑件可制造性检查与缩水率补偿。

## 安装

    dsh plugin --profile web add github:moldkey/dsh-injection-molding

## 工具

- `injection_dfm`：壁厚/脱模角/圆角/筋厚/缩水率检查
- `injection_shrink`：材料缩水率与模具尺寸

更多工具：https://deepseekbase.com/zh/tools/
